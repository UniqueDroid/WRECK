# Template

Don't copy this by hand – `wreck init "<model name>"` creates a new device with this layout
(`profile.json`, `ledger.jsonl`, `provenance.jsonl`, `LEGAL-ACK.md`, `reports/`) plus `private/<id>/`.
Field meanings and status values: `docs/EVIDENCE.md`. A filled-in example: `devices/m78-jl701n/`.
