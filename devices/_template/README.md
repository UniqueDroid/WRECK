# Vorlage

Nicht von Hand kopieren – `wreck init "<Modellname>"` legt ein neues Gerät mit diesem Aufbau an
(`profile.json`, `ledger.jsonl`, `provenance.jsonl`, `LEGAL-ACK.md`, `reports/`) plus `private/<id>/`.
Feldbedeutungen und Statuswerte: `docs/EVIDENCE.md`. Ein ausgefülltes Beispiel: `devices/m78-jl701n/`.
